What do orc names sound like?

Orc names lean into short, sharp syllables with hard consonants and rolled Rs. They are built to be shouted across a battlefield. This free orc name generator (and random name generator, name creator, and random name maker all in one) draws from a curated set of prefixes, middles, and suffixes tuned to that culture. Common opening sounds include Gr, Ur, Gor, Mog, Thr, and K; common endings include -gul, -nash, -rok, -tar, -mok, and -drak.
